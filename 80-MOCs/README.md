# Maps of Content (MOCs)

Navigation hubs for knowledge categories using Zettelkasten principles.

## What are MOCs?

Maps of Content (MOCs) are index notes that help navigate and organize knowledge within a category. They serve as entry points to explore related concepts and see the big picture of a knowledge domain.

## Structure

MOCs are organized by category and stored in this folder:
- Format: `[Category]_MOC.md` or `[Category]_Index.md`
- Example: `PySpark_MOC.md`, `AWS_Index.md`

## How to Use

1. **Create MOC**: Use `!moc [Category]` command
2. **Auto-updates**: MOCs are automatically updated when new notes are added to categories
3. **Navigation**: Use MOCs to discover related notes and concepts
4. **Cross-linking**: MOCs link to other category MOCs for cross-domain exploration

## MOC Contents

Each MOC typically includes:
- Overview of the category
- Atomic Notes section (single-concept notes)
- Study Notes section (comprehensive notes)
- Concepts grouped by themes
- Links to related category MOCs

---

**Tip**: MOCs help you see the forest, not just the trees. They're especially useful when a category has 10+ notes.
