# Inbox

Landing zone for raw thoughts, unparsed PDFs, and brain dumps.

## How to Use

1. Dump raw thoughts, ideas, or content here
2. Use `!inbox-process` command to organize items
3. AI will suggest categories and help you organize

## Processing

Items in the inbox are processed daily. The AI will:
- Auto-suggest appropriate categories
- Help move items to proper locations
- Create proper structure with frontmatter and links

---

**Tip**: Don't worry about organization here - just capture everything. Processing happens later!
