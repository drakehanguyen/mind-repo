# Metadata

System documentation, templates, and configuration files.

## Contents

This folder contains:
- **AGENT.md** (at root) - Complete AI agent instructions
- **Templates/** - Note templates for various types
- System documentation and reference materials

## Purpose

The Metadata folder stores everything needed to understand and operate the MindRepo system:
- Command specifications
- System architecture documentation
- Templates for creating new notes
- Configuration references

## Usage

- Templates can be used with Obsidian's template plugin
- Reference AGENT.md for complete command documentation
- System documentation helps maintain consistency
