# Areas

Long-term responsibilities that need ongoing maintenance (PARA method).

## What Are Areas?

Areas are standards you want to maintain over time. They don't have deadlines but require regular attention to avoid problems.

## Default Areas

Each area has its own subfolder:

- **Career/Career.md** - Professional development, career goals, skill tracking
- **Health/Health.md** - Exercise routines, medical records, wellness goals
- **Hobbies/Hobbies.md** - Personal hobby projects and interests
- **Languages/Languages.md** - Language learning progress and resources

## Structure

Areas are organized in subfolders to allow for expansion:
```
/20-Areas/
  ├─ Career/
  │   └─ Career.md
  ├─ Health/
  │   └─ Health.md
  └─ ...
```

This structure allows you to add additional files to an area if needed (e.g., `Career/Goals.md`, `Career/Skills.md`).

## Adding New Areas

You can create additional area folders as needed:
- Finance/ - Budget tracking, investments
- Home/ - Household maintenance, standards
- Relationships/ - Personal relationship maintenance
- etc.

Each new area should have its own subfolder with a main file (e.g., `Finance/Finance.md`).

## Difference from Projects

- **Areas**: Ongoing, no deadline, maintain standards
- **Projects**: Time-bound, specific outcome, completion date

## Usage

- Update area files periodically (not daily)
- Track goals, standards, and progress
- Link to related projects or resources
- Use for long-term planning and reflection

---

**Tip**: Areas are your "life maintenance" - things that matter but don't have deadlines.
